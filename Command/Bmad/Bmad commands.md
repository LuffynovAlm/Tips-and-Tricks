# Bmad Commands

## Installation

| Command | Description |
|---|---|
| `uv pip install bmad` | install initial de Bmad, prerequis UV |

## Workflow orchestration

| Command | Description |
|---|---|
| `bmad-check-implementation-readiness` | DoR gate (architecture-readiness) |
| `bmad-create-epics-and-stories` | Decompose PRD into backlog |
| `bmad-create-story` | Detail a single story |
| `bmad-dev-story` | Implement a story with architecture guidance |
| `bmad-code-review` | Review code changes |
| `bmad-retrospective` | Debrief after epic completion |
