CLI (code)12

code .
Open the current folder in VS Code
code <file>
Open a file
code -r <path>
Open in the last active window (reuse)
code -n
Open a new window
code -g <file>:<line>
Open a file at a given line
code -d <file1> <file2>
Diff two files
code <name>.code-workspace
Open a multi-root workspace
code --list-extensions
List installed extensions
code --install-extension <id>
Install an extension (e.g. anthropic.claude-code)
code --uninstall-extension <id>
Uninstall an extension
code --disable-extensions
Start with all extensions disabled (troubleshooting)
code --profile "<name>"
Open with a specific profile
