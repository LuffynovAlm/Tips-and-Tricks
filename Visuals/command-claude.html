Tokens & Cost11

/cost
Token and dollar cost of the current session — copy it into the deliverable before closing
/context
See what fills the context (system prompt, MCP tools, memory files, messages) to spot token hogs
/compact <focus>
Summarize the conversation, keeping what you name (e.g. /compact keep the API decisions)
/clear
Drop all context between unrelated tasks — the cheapest token is the one you don't resend
/model haiku / /model sonnet
Switch to a cheaper model for routine work
/effort low
Lower reasoning effort (fewer thinking tokens) for simple tasks
/mcp
Disable MCP servers you don't use — their tool definitions use context on every request
/statusline
Show session cost / context % permanently in the status line
claude --max-budget-usd <amount>
Hard spending cap for the session
claude -p "query" --output-format json
Headless run whose JSON result includes total_cost_usd and token usage — log it in CI
npx ccusage@latest
Community tool: daily / per-session token and cost report from local Claude Code logs

CLI Commands & Flags (run in the shell, not inside a session)20

claude
Start an interactive Claude Code session
claude "query"
Start a session with an initial prompt
claude -p "query"
Run a one-off query, print the response, then exit
cat file | claude -p "query"
Pipe content into a one-off query
claude -p "query" --output-format json
One-off query with JSON output (also stream-json)
claude -c / --continue
Continue the most recent conversation in the current directory
claude -r <session> / --resume
Resume a specific session by ID or name
claude -r <session> --fork-session
Resume into a new session ID, leaving the original conversation untouched
claude --model <model>
Start a session with a specific model
claude --effort <level>
Start a session with a set reasoning effort level
claude --permission-mode <mode>
Start in a specific permission mode (e.g. auto, manual, plan)
claude --add-dir <path>
Add additional working directories at startup
claude --bg "prompt" / --background
Start as a background agent session
claude --max-budget-usd <amount>
Set a spending cap before the session stops
claude update
Update Claude Code to the latest version
claude doctor
Run diagnostics and setup health checks
claude mcp add
Add a new MCP server with a specified transport
claude mcp list
List all configured MCP servers and their status
claude mcp remove <name>
Remove a configured MCP server
claude plugin
Manage plugins and view the plugin marketplace
