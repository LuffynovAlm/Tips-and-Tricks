# GithubCopilot Shortcuts

VS Code, Windows default keybindings.

| Shortcut | Action | Important |
|---|---|---|
| Tab | Accept inline suggestion | ★ |
| Esc | Dismiss inline suggestion |  |
| Ctrl+Right | Accept next word of the suggestion |  |
| Alt+] / Alt+[ | Next / previous inline suggestion |  |
| Alt+\ | Trigger an inline suggestion |  |
| Ctrl+Enter | Open the completions panel (multiple suggestions) |  |
| Ctrl+I | Inline chat in the editor or terminal | ★ |
| Ctrl+Alt+I | Open the Chat view | ★ |
| Ctrl+Shift+I | Open Chat in agent mode | ★ |
| Ctrl+N | New chat session (focus in Chat view) |  |
| Ctrl+Up | Navigate previous requests (focus in Chat input) |  |
