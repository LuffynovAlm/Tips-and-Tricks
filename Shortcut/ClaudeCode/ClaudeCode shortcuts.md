# ClaudeCode Shortcuts

| Shortcut | Action |
|---|---|
| Esc | Interrupt Claude mid-response |
| Esc, Esc | Rewind — jump back to an earlier message (or clear current input) |
| Ctrl+Esc | Focus the Claude Code panel (VS Code) |
| Ctrl+C | Cancel current operation |
| Shift+Tab | Cycle permission modes (default → accept edits → plan) |
| Alt+K | Insert an @-mention of the current editor selection (VS Code) |
| Ctrl+R | Reverse-search the prompt history |
| Up / Down | Navigate prompt history |
| Shift+Enter | New line in the prompt (after `/terminal-setup` in the terminal) |
| \+Enter | New line in the prompt (works in every terminal) |
| Ctrl+O | Toggle verbose transcript view |
| Ctrl+T | Show / hide the task (todo) list |
| Ctrl+B | Send a running command to the background |
| Ctrl+G | Edit the prompt in your external editor |
| Ctrl+V / Alt+V | Paste an image from the clipboard (Alt+V on Windows) |
| Alt+P | Switch model without clearing the prompt |
| Ctrl+L | Clear the terminal screen (keeps conversation) |
| Ctrl+D | Exit the session |
| Ctrl+] | Reopen the most recent artifact from this session |
